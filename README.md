\# SQL Fundamentals



A collection of foundational SQL scripts covering schema creation, foreign key constraints, self-joins, and set operations.



\## Features

\- \*\*Employee Schema\*\*: Hierarchical table structure with self-referential foreign keys.

\- \*\*Self-Joins\*\*: Mapping employees to their direct managers.

\- \*\*Set Operations\*\*: Demonstrating `UNION` vs. `UNION ALL`.



\## Execution

Run `sql\_basics\_sandbox.sql` in MySQL Workbench or any standard SQL engine.
